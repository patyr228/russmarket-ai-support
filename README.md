# Автоматизация утренней сводки support-отдела («Руссмаркет»)[cite: 4]

## 2. Введение[cite: 4]
Гибридное решение для автоматической сверки статусов CRM и рабочих чатов[cite: 4].  
Система формирует приоритезированную утреннюю сводку для support-отдела, чтобы сотрудники быстрее замечали кейсы, требующие вмешательства[cite: 4].  
Решение работает полностью локально (Ollama) с учётом требований 152-ФЗ[cite: 4].

---

## 3. Способ обработки[cite: 4]
Предлагается гибридный подход[cite: 4]:
1. **Rule-based подготовка данных**[cite: 4]: Скрипт собирает статусы из CRM и историю сообщений из рабочих чатов, отсекает системный шум и выполняет базовые проверки дедлайнов[cite: 4].
2. **Локальная LLM + Structured Outputs**[cite: 4]: Модель анализирует неструктурированные переписки, сопоставляет их с официальными статусами CRM и возвращает результат строго по схеме Pydantic[cite: 4].
3. **Безопасность**[cite: 4]: Вся обработка персональных данных происходит локально, без передачи во внешние облачные API[cite: 4].

## 4. Сводка по четырём кейсам (понедельник, 10:00)[cite: 5]

### С-17 - Оформление сотрудника[cite: 5]
* **В CRM:** первый выход завтра, документы ожидаются[cite: 5].
* **Из чата:** сотрудник отправил фото документов руководителю в личку[cite: 5].
* **Нужно вмешательство:** да (документы не дошли до системы)[cite: 5].
* **С чего начать:** запросить у руководителя пересылку документов в CRM[cite: 5].

### С-24 - Увольнение сотрудника[cite: 5]
* **В CRM:** последний рабочий день сегодня, подтверждение руководителя отсутствует[cite: 5].
* **Из чата:** сотрудник говорит, что с руководителем всё обсудили[cite: 5].
* **Нужно вмешательство:** да (нет официального подтверждения)[cite: 5].
* **С чего начать:** запросить у руководителя письменное подтверждение закрытия смены[cite: 5].

### П-08 - Поставка карт[cite: 5]
* **В CRM:** доставка запланирована до 10:00, статус «В пути»[cite: 5].
* **Из чата:** курьер сообщил о задержке до 13:00[cite: 5].
* **Нужно вмешательство:** да (дедлайн уже просрочен)[cite: 5].
* **С чего начать:** оповестить точку о новом времени прибытия и зафиксировать отклонение[cite: 5].

### П-09 - Поставка карт[cite: 5, 6]
* **В CRM:** статус «Принято», приёмка подтверждена в 09:20[cite: 6].
* **Из чата:** получатель подтвердил получение и проверку количества[cite: 6].
* **Нужно вмешательство:** нет[cite: 6].
* **Действия:** не требуются[cite: 6].

## 5. Описание первого запуска[cite: 6]
Решение забирает данные по API из CRM и историю сообщений из рабочих чатов[cite: 6].  
Сводка формируется по расписанию утром и отправляется в закрытый канал или дашборд support-отдела[cite: 6].  
Сотрудник перед началом работы смотрит сводку, в первую очередь обращая внимание на кейсы с высоким приоритетом[cite: 6]. Перед действием рекомендуется быстро сверить вывод с оригинальной перепиской[cite: 6].  
На старте запускаем систему в тестовом режиме параллельно с ручной работой в течение одной недели и совместно с руководителем support-отдела замеряем время обработки инцидентов «до» и «после»[cite: 6].
